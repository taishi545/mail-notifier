プライバシーポリシー / Privacy Policy

最終更新日 / Last updated: 2026-11-25

1. このツールについて / About this tool

mail-notifier は、開発者本人だけが自分の Google アカウントで使う個人用のツールです。

mail-notifier is a personal tool used only by its developer with the developer's own Google account.

2. 読むデータ / Data accessed

Gmail API の gmail.metadata スコープで、受信トレイに新しく届いたメールの見出し（差出人・件名など）と、メールの ID、変更の目印（historyId）だけを読みます。本文や添付ファイルは読みません。

Using the Gmail API gmail.metadata scope, the tool reads only the headers (such as From and Subject), message IDs, and history IDs of messages newly added to the inbox. Message bodies and attachments are never read.

3. データの使い方 / How data is used

差出人があらかじめ決めた 1 つのアドレスと一致したときだけ、差出人の名前と件名を、開発者本人の Discord のチャンネルに送ります。それ以外の目的には使いません。

Only when the sender matches one pre-configured address, the sender's name and the subject are posted to the developer's own Discord channel. The data is not used for any other purpose.

4. 保存するデータ / Data stored

  • 二重に通知しないために、通知したメールの ID（最大 200 件）と、どこまで確認したかの目印（historyId）だけを、開発者本人の Google Cloud Storage に保存します。差出人・件名・本文は保存しません。
  • To avoid duplicate notifications, only the IDs of notified messages (up to 200) and the last processed history ID are stored in the developer's own Google Cloud Storage. Senders, subjects, and bodies are not stored.
  • OAuth の認証情報（リフレッシュトークン）は、開発者本人の Google Cloud Secret Manager に保存します。
  • OAuth credentials (refresh token) are stored in the developer's own Google Cloud Secret Manager.

5. 第三者への提供 / Sharing

データを販売したり、広告に使ったり、第三者に提供したりしません。通知の送り先は、開発者本人の Discord のチャンネルだけです。

Data is never sold, used for advertising, or shared with third parties. Notifications are sent only to the developer's own Discord channel.

The use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

6. 削除とアクセスの取り消し / Deletion and revoking access

Google アカウントの「セキュリティ」→「サードパーティのアクセス」から、いつでもこのツールへのアクセスを取り消せます。取り消すと、このツールはメールの見出しを読めなくなります。保存している ID と目印は、開発者がバケットを削除することで消えます。

Access can be revoked at any time from the Google Account "Security" → "Third-party access" page. After revocation, the tool can no longer read any message metadata. The stored IDs and history ID are deleted when the developer deletes the storage bucket.

7. 変更 / Changes

このポリシーを変更するときは、このページを更新します。

Any changes to this policy will be posted on this page.
