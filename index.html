mail-notifier

個人用の通知ツールです。開発者本人の Gmail に、あらかじめ決めた差出人からメールが届いたとき、その差出人の名前と件名を、開発者本人の Discord のチャンネルに通知します。

A personal notification tool. When an email from one pre-configured sender arrives in the developer's own Gmail inbox, it posts the sender's name and the subject line to the developer's own Discord channel.

使っている Google のデータ / Google data used

  • Gmail の見出し（差出人・件名などのメタデータ）だけを読みます。本文や添付ファイルは読みません（スコープ：gmail.metadata）。
  • Only message metadata (headers such as From and Subject) is read. Message bodies and attachments are never accessed (scope: gmail.metadata).

利用者 / Users

このツールは開発者本人だけが、自分のアカウントで使うためのものです。ほかの人に向けたサービスではありません。

This tool is used only by its developer, with the developer's own account. It is not offered to anyone else.
